Antes de começar

Uma loja de informática exporta as vendas do sistema em um CSV por mês. Os arquivos vêm com espaços sobrando, regiões escritas de jeitos diferentes e linhas vazias, e a categoria do produto fica em outra planilha. A turma vai montar um processo que limpa, junta e resume tudo, e que no mês seguinte roda com um clique.

Ao final da aula, o aluno sabe

  • Importar e combinar vários arquivos de uma pasta
  • Limpar texto, remover linhas vazias e definir tipos de dados
  • Criar colunas calculadas e mesclar com um cadastro
  • Ler o código M gerado pelas etapas
  • Montar tabelas dinâmicas, gráficos e segmentações conectadas
  • Atualizar o dashboard quando chega um arquivo novo

Módulo 1

Conectar o Power Query à pasta de vendas

Em vez de abrir cada CSV, vamos apontar o Power Query para a pasta inteira. Todo arquivo novo que cair nela entra no relatório na próxima atualização.

1.1

Abra a guia Dados

Abra uma pasta de trabalho em branco e clique na guia Dados. O grupo Obter e Transformar Dados, à esquerda, é a porta de entrada do Power Query.

1.2

Obter Dados › De Arquivo › Da Pasta

Clique em Obter Dados›De Arquivo›Da Pasta. Use Da Pasta (e não De Text/CSV) porque os dados chegam divididos em um arquivo por mês.

1.3

Selecione a pasta Vendas

Navegue até Documentos › Claude outputs › Aula_PowerQuery, clique uma vez na pasta Vendas e clique em Abrir.

Dica

Não entre na pasta com duplo clique. A janela pede uma pasta; se você entrar nela, o campo fica vazio e o botão Abrir não aceita.

1.4

Confira a lista de arquivos e clique em Combinar

O Power Query lista os 3 CSVs com metadados (Name, Extension, datas). A coluna Content guarda o arquivo em si (Binary).

  • Combinar: junta o conteúdo dos arquivos.
  • Carregar: traz só esta lista de metadados para o Excel.
  • Transformar Dados: abre o editor com a lista, sem combinar.
1.5

Combinar e Transformar Dados

No menu do botão, escolha Combinar›Combinar e Transformar Dados. Assim os dados combinados abrem no editor para limpeza antes de ir para a planilha.

1.6

Ajuste a leitura dos arquivos

A janela Combinar Arquivos usa o primeiro arquivo como amostra. Confira os três campos marcados:

  • Origem do Arquivo: 65001: Unicode (UTF-8). Se aparecer Ã© no lugar de é, a codificação está errada.
  • Delimitador: Ponto e vírgula (padrão de CSV brasileiro).
  • Detecção de Tipo de Dados: primeiras 200 linhas.

Clique em OK.

1.7

Conheça o Editor do Power Query

Os três meses chegaram empilhados. Antes de mexer, reconheça as áreas da tela:

  • Consultas (esquerda): a consulta principal e a pasta Transformar Arquivo de Vendas, com as consultas auxiliares que o Excel criou para combinar. Não apague essa pasta.
  • Barra de fórmulas: mostra o código M da etapa selecionada.
  • Etapas Aplicadas (direita): a receita gravada. Cada clique vira uma etapa que se repete sozinha em toda atualização.

No rodapé: 8 colunas, 390 linhas. Repare na linha 27 com null: os CSVs têm linhas vazias.

Módulo 2

Limpar e padronizar os dados

Os CSVs simulam dados reais: linhas vazias, espaços sobrando antes dos nomes e regiões escritas como SUDESTE, sudeste ou Sudeste. Uma tabela dinâmica trataria cada variação como uma região diferente.

2.1

Renomeie a consulta para fVendas

Em Configurações da Consulta › Propriedades › Nome, troque Vendas por fVendas e tecle Enter.

Dica

Convenção usada em modelagem: f para tabela fato (eventos, como vendas) e d para dimensão (cadastros, como produtos). Os nomes aparecem depois na lista de campos da tabela dinâmica.

2.2

Remova as linhas vazias pelo filtro de ID_Venda

Clique na seta do cabeçalho ID_Venda e escolha Remover Vazio. O rodapé passa de 390 para 385 linhas.

Atenção

Pegadinha para discutir com a turma. O comando Página Inicial›Remover Linhas›Remover Linhas em Branco não resolve aqui: ele só remove linhas com todas as colunas vazias, e a coluna Nome da Origem (nome do arquivo) está sempre preenchida. Por isso a etapa Linhas em Branco Removidas aparece na lista mas não muda nada. Filtrar a coluna-chave é a forma confiável.

2.3

Selecione Vendedor e Região e apare os espaços

Clique no cabeçalho Vendedor, segure Ctrl e clique em Região. Depois vá em Transformar›Formato›Cortar.

Cortar remove espaços no início e no fim do texto (Text.Trim). "  Bruno Lima " vira "Bruno Lima".

Dica

Em algumas versões do Excel o mesmo comando se chama Aparar.

2.4

Padronize maiúsculas e minúsculas

Com as duas colunas ainda selecionadas: Transformar›Formato›Colocar Cada Palavra em Maiúscula (Text.Proper).

2.5

Confira o resultado

SUDESTE, sudeste e Sudeste viraram Sudeste; centro-oeste virou Centro-Oeste. Duas etapas novas entraram na lista: Texto Aparado e Colocar Cada Palavra Em Maiúscula.

Módulo 3

Criar colunas calculadas

O CSV não traz o valor da venda nem o mês por extenso. Criamos as duas colunas no Power Query para que o Excel receba a base pronta.

3.1

Coluna Personalizada: Faturamento

Adicionar Coluna›Coluna Personalizada. Preencha:

  • Nome da nova coluna: Faturamento
  • Fórmula: = [Quantidade] * [Preço Unitário]

Confira a mensagem Nenhum erro de sintaxe detectado e clique em OK.

Dica

Dê duplo clique em um nome na lista Colunas disponíveis para inseri-lo na fórmula já com colchetes e sem erro de digitação.

3.2

Defina o tipo Moeda

Coluna personalizada nasce com o tipo ABC123 (qualquer). Com Faturamento selecionada, vá em Transformar›Tipo de Dados›Moeda.

Dica

Sem tipo definido, o Excel pode receber a coluna como texto e a tabela dinâmica não soma.

3.3

Extraia o nome do mês

Selecione a coluna Data e vá em Adicionar Coluna›Data›Mês›Nome do Mês. A nova coluna mostra janeiro, fevereiro, março.

Módulo 4

Trazer a categoria e o custo do cadastro

Categoria e custo ficam em outra planilha, Cadastro_Produtos.xlsx. É o PROCV do Power Query: a mesclagem.

4.1

Nova Fonte › Arquivo › Pasta de Trabalho do Excel

Ainda no editor, em Página Inicial›Nova Fonte›Arquivo›Pasta de Trabalho do Excel.

4.2

Selecione Cadastro_Produtos.xlsx

Na pasta Aula_PowerQuery, selecione Cadastro_Produtos.xlsx e clique em Importar.

4.3

Escolha a tabela tbProdutos no Navegador

O arquivo oferece dois itens: tbProdutos (ícone de tabela, formatada com Ctrl+T) e Produtos (a planilha inteira). Prefira a tabela: ela cresce junto com os dados e não traz células soltas. Clique em OK.

Depois, renomeie a nova consulta para dProdutos, como no passo 2.1.

4.4

Mesclar Consultas

Volte para fVendas no painel esquerdo e clique em Página Inicial›Mesclar Consultas.

  1. Na tabela de cima (fVendas), clique na coluna Produto.
  2. Na lista, escolha dProdutos e clique na coluna Produto dela.
  3. Tipo de Junção: Externa esquerda (todas as vendas, mais o que encontrar no cadastro).

O rodapé confirma 385 de 385 linhas: todo produto vendido existe no cadastro. Clique em OK.

Dica

Se o total ficar abaixo de 385, existe produto escrito de forma diferente nos dois arquivos. Limpe a coluna antes de mesclar.

4.5

Expanda Categoria e Custo Unitário

A mesclagem cria uma coluna dProdutos com o valor Table em cada linha. Clique no ícone de expandir do cabeçalho e:

  • marque só Categoria e Custo Unitário (Produto já existe em fVendas);
  • desmarque Usar o nome da coluna original como prefixo, para não ficar dProdutos.Categoria.
4.6

Crie a coluna Lucro

Repita o passo 3.1 com:

  • Nome: Lucro
  • Fórmula: = [Faturamento] - [Quantidade] * [Custo Unitário]

Defina o tipo Moeda como no passo 3.2. A barra de fórmulas mostra o M gerado; a consulta fecha com 13 colunas.

Módulo 5

Por trás dos cliques: a linguagem M

Cada etapa da lista é uma linha de código M. Mostrar o código na projeção ajuda a turma a entender que o Power Query é uma receita reproduzível, não uma edição manual.

5.1

Abra o Editor Avançado

Página Inicial›Editor Avançado. O código abaixo é o mesmo da tela, com comentários para a aula. Pode ser colado no Editor Avançado de uma consulta nova; ajuste só o caminho da pasta na primeira linha.

fVendas · código M comentado
let
    // 1. Fonte: lê TODOS os arquivos da pasta (troque o caminho se mover a pasta)
    Fonte = Folder.Files("C:\Users\Professor\Documents\Claude outputs\Aula_PowerQuery\Vendas"),

    // 2. Etapas criadas pelo "Combinar e Transformar": ignora ocultos e aplica a
    //    função "Transformar Arquivo" (gerada a partir do arquivo de amostra) a cada CSV
    #"Arquivos Ocultos Filtrados1" = Table.SelectRows(Fonte, each [Attributes]?[Hidden]? <> true),
    #"Invocar Função Personalizada1" = Table.AddColumn(#"Arquivos Ocultos Filtrados1", "Transformar Arquivo", each #"Transformar Arquivo"([Content])),
    #"Colunas Renomeadas1" = Table.RenameColumns(#"Invocar Função Personalizada1", {"Name", "Nome da Origem"}),
    #"Outras Colunas Removidas1" = Table.SelectColumns(#"Colunas Renomeadas1", {"Nome da Origem", "Transformar Arquivo"}),
    #"Coluna de Tabela Expandida1" = Table.ExpandTableColumn(#"Outras Colunas Removidas1", "Transformar Arquivo", Table.ColumnNames(#"Transformar Arquivo"(#"Arquivo de Amostra"))),

    // 3. Tipos de dados (detecção automática)
    #"Tipo Alterado" = Table.TransformColumnTypes(#"Coluna de Tabela Expandida1",{{"Nome da Origem", type text}, {"ID_Venda", Int64.Type}, {"Data", type date}, {"Vendedor", type text}, {"Região", type text}, {"Produto", type text}, {"Quantidade", Int64.Type}, {"Preço Unitário", type number}}),

    // 4. Limpeza: a 1ª etapa não removeu nada (Nome da Origem nunca é vazio); o filtro em ID_Venda resolve
    #"Linhas em Branco Removidas" = Table.SelectRows(#"Tipo Alterado", each not List.IsEmpty(List.RemoveMatchingItems(Record.FieldValues(_), {"", null}))),
    #"Linhas Filtradas" = Table.SelectRows(#"Linhas em Branco Removidas", each [ID_Venda] <> null and [ID_Venda] <> ""),
    #"Texto Aparado" = Table.TransformColumns(#"Linhas Filtradas",{{"Vendedor", Text.Trim, type text}, {"Região", Text.Trim, type text}}),
    #"Colocar Cada Palavra Em Maiúscula" = Table.TransformColumns(#"Texto Aparado",{{"Vendedor", Text.Proper, type text}, {"Região", Text.Proper, type text}}),

    // 5. Colunas calculadas
    #"Personalização Adicionada" = Table.AddColumn(#"Colocar Cada Palavra Em Maiúscula", "Faturamento", each [Quantidade] * [Preço Unitário]),
    #"Tipo Alterado1" = Table.TransformColumnTypes(#"Personalização Adicionada",{{"Faturamento", Currency.Type}}),
    #"Nome do Mês Inserido" = Table.AddColumn(#"Tipo Alterado1", "Nome do Mês", each Date.MonthName([Data]), type text),

    // 6. Mesclagem com o cadastro (equivalente a um PROCV)
    #"Consultas Mescladas" = Table.NestedJoin(#"Nome do Mês Inserido", {"Produto"}, dProdutos, {"Produto"}, "dProdutos", JoinKind.LeftOuter),
    #"dProdutos Expandido" = Table.ExpandTableColumn(#"Consultas Mescladas", "dProdutos", {"Categoria", "Custo Unitário"}, {"Categoria", "Custo Unitário"}),

    // 7. Lucro
    #"Personalização Adicionada1" = Table.AddColumn(#"dProdutos Expandido", "Lucro", each [Faturamento] - [Quantidade] * [Custo Unitário]),
    #"Tipo Alterado2" = Table.TransformColumnTypes(#"Personalização Adicionada1",{{"Lucro", Currency.Type}})
in
    #"Tipo Alterado2"

Módulo 6

Carregar os dados no Excel

Até aqui nada foi gravado na planilha: o editor só mostra uma prévia. Agora as consultas viram tabelas do Excel.

6.1

Fechar e Carregar Para...

Clique na seta de Página Inicial›Fechar e Carregar e escolha Fechar e Carregar Para.... O botão direto carregaria tudo como tabela, sem perguntar.

6.2

Escolha Tabela em Nova planilha

Na janela Importar Dados, marque Tabela e Nova planilha e clique em OK.

A escolha vale para as duas consultas novas. Em um projeto maior, deixe a dimensão como Apenas Criar Conexão para não ocupar uma planilha só com o cadastro.

6.3

Confira as consultas carregadas

O painel Consultas e Conexões mostra fVendas: 385 linhas carregadas e dProdutos: 10 linhas carregadas. As consultas auxiliares ficam como Apenas conexão.

Módulo 7

Resumir com Tabela e Gráfico Dinâmico

A tabela fVendas é a base. O dashboard é feito de tabelas dinâmicas que leem essa base e são atualizadas junto com ela.

7.1

Resumir com Tabela Dinâmica

Clique em qualquer célula da tabela fVendas e vá em Design da Tabela›Resumir com Tabela Dinâmica. O intervalo já vem como fVendas. Mantenha Nova Planilha e clique em OK.

Dica

Usar o nome da tabela como origem faz a dinâmica enxergar as linhas novas que entrarem após cada atualização.

7.2

Monte: Mês nas linhas, Faturamento e Lucro nos valores

Na lista de campos, marque Nome do Mês (vai para Linhas), Faturamento e Lucro (vão para Valores como Soma).

Os meses saem em ordem de calendário, não alfabética, porque o Excel reconhece nomes de mês pelas listas personalizadas. Para formatar, selecione os valores e tecle Ctrl+Shift+$.

7.3

Insira um Gráfico Dinâmico

Com uma célula da dinâmica selecionada: Análise de Tabela Dinâmica›Gráfico Dinâmico › Colunas › Coluna Agrupada › OK.

Crie uma planilha chamada Dashboard, recorte o gráfico (Ctrl+X) e cole lá. Renomeie a planilha da dinâmica para Tabelas.

Módulo 8

Montar o dashboard interativo

8.1

Inserir Segmentação de Dados

Selecione o gráfico e vá em Análise de Gráfico Dinâmico›Inserir Segmentação de Dados. Marque Vendedor, Região e Categoria e clique em OK.

8.2

Posicione as segmentações

As três caixas aparecem empilhadas. Arraste para uma coluna lateral e ajuste o estilo na guia Segmentação.

8.3

Crie as outras tabelas dinâmicas e os cartões

Módulo 9

Atualizar com um clique

Este é o momento de mostrar para a turma por que o Power Query vale o trabalho: chegou o mês de abril e ninguém refaz nada.

9.1

Coloque o arquivo de abril na pasta

Copie Vendas_2026_04_Abr.csv da pasta Extra para a pasta Vendas. É o que acontece no dia a dia, quando o sistema exporta um arquivo novo.

Exercícios para a turma

E1Filtrar por trimestre

Crie uma coluna com o trimestre e use-a em uma nova segmentação.

No editor, selecione Data › Adicionar Coluna › Data › Trimestre › Trimestre do Ano. Feche e carregue, atualize as dinâmicas e insira a segmentação pelo campo novo. Lembre de ligá-la às dinâmicas em Conexões de Relatório.

E2Margem de lucro

Mostre a margem (%) por região. Faça no Power Query ou na tabela dinâmica?

Na dinâmica: Análise de Tabela Dinâmica › Campos, Itens e Conjuntos › Campo Calculado com =Lucro/Faturamento. Uma coluna de margem por linha no Power Query daria resultado errado ao ser somada ou ter a média calculada. Bom gancho para discutir métrica por linha e métrica agregada.

E3Linha do tempo

Adicione um filtro de período por datas.

Análise de Tabela Dinâmica › Inserir Linha do Tempo › campo Data. Depois, botão direito › Conexões de Relatório e marque todas as dinâmicas.

E4Caminho da pasta como parâmetro

Faça a consulta funcionar no computador de qualquer aluno sem editar o código.

Página Inicial › Gerenciar Parâmetros › Novo Parâmetro: nome PastaVendas, tipo Texto, valor com o caminho. No Editor Avançado, troque a linha da fonte por Fonte = Folder.Files(PastaVendas),.

E5Investigar a mesclagem

Edite o CSV de março trocando um Monitor 27 pol por monitor 27 pol. O que acontece depois de atualizar?

A mesclagem é sensível a maiúsculas: a venda fica com Categoria e Custo vazios, e o lucro dela sai igual ao faturamento. Correção: padronizar a coluna Produto (Formato) nas duas consultas antes de mesclar.

Atalho do professor: layout via VBA

Opcional. Depois do passo 8.2, esta macro cria as dinâmicas da tabela do passo 8.3, os cartões de KPI e os gráficos, liga as segmentações e organiza o painel como no print. É a mesma rotina usada para montar o dashboard desta apostila. Útil para preparar a aula ou para recuperar o arquivo de um aluno que se perdeu.

Módulo VBA · MontarDashboard
' Pré-requisitos: planilha "Tabelas" com a 1ª tabela dinâmica (Mês x Faturamento/Lucro)
' e planilha "Dashboard" com o 1º gráfico dinâmico e as 3 segmentações (passos 7.1 a 8.2).
' Alt+F11 › Inserir › Módulo › cole › F5. Salve depois como .xlsx (Salvar e apagar recursos).
Sub MontarDashboard()
    Dim wb As Workbook, wsT As Worksheet, wsD As Worksheet, pc As PivotCache
    Dim pt As PivotTable, ptR As PivotTable, ptC As PivotTable, ptV As PivotTable, ptK As PivotTable
    Dim co As ChartObject, sc As SlicerCache, r As Range, c As Range, s As Shape, i As Integer
    Dim addr, lbl, frm, fmt
    Set wb = ActiveWorkbook: Set wsT = wb.Worksheets("Tabelas"): Set wsD = wb.Worksheets("Dashboard")
    wsT.PivotTables(1).Name = "ptMes"
    Set pc = wsT.PivotTables(1).PivotCache

    Set ptR = pc.CreatePivotTable(wsT.Range("F3"), "ptRegiao")
    ptR.PivotFields("Região").Orientation = xlRowField
    ptR.AddDataField ptR.PivotFields("Faturamento"), "Total Faturamento", xlSum
    ptR.PivotFields("Região").AutoSort xlDescending, "Total Faturamento"
    Set ptC = pc.CreatePivotTable(wsT.Range("J3"), "ptCategoria")
    ptC.PivotFields("Categoria").Orientation = xlRowField
    ptC.AddDataField ptC.PivotFields("Faturamento"), "Total Faturamento", xlSum
    ptC.PivotFields("Categoria").AutoSort xlDescending, "Total Faturamento"
    Set ptV = pc.CreatePivotTable(wsT.Range("N3"), "ptVendedor")
    ptV.PivotFields("Vendedor").Orientation = xlRowField
    ptV.AddDataField ptV.PivotFields("Faturamento"), "Total Faturamento", xlSum
    ptV.PivotFields("Vendedor").AutoSort xlAscending, "Total Faturamento"
    Set ptK = pc.CreatePivotTable(wsT.Range("R3"), "ptKPI")
    ptK.AddDataField ptK.PivotFields("Faturamento"), "Total Faturamento", xlSum
    ptK.AddDataField ptK.PivotFields("Lucro"), "Total Lucro", xlSum
    ptK.AddDataField ptK.PivotFields("ID_Venda"), "Qtd Vendas", xlCount
    For Each pt In wsT.PivotTables: pt.DataBodyRange.NumberFormat = "$ #,##0.00": Next pt
    ptK.DataBodyRange.Cells(1, 3).NumberFormat = "0"

    ' Liga todas as segmentações a todas as dinâmicas
    For Each sc In wb.SlicerCaches
        sc.PivotTables.AddPivotTable ptR: sc.PivotTables.AddPivotTable ptC
        sc.PivotTables.AddPivotTable ptV: sc.PivotTables.AddPivotTable ptK
    Next sc

    ' Grade e título
    wsD.Activate: ActiveWindow.DisplayGridlines = False
    wsD.Cells.Interior.Color = RGB(243, 245, 247)
    wsD.Columns("A").ColumnWidth = 2: wsD.Columns("B:C").ColumnWidth = 13
    wsD.Columns("D").ColumnWidth = 2: wsD.Columns("E:T").ColumnWidth = 8.5
    wsD.Rows("1:60").RowHeight = 15: wsD.Rows(2).RowHeight = 34
    With wsD.Range("B2:T2")
        .Merge: .Value = "  Dashboard de Vendas 2026  |  Power Query + Tabela Dinâmica"
        .Font.Size = 18: .Font.Bold = True: .Font.Color = vbWhite
        .Interior.Color = RGB(33, 115, 70): .VerticalAlignment = xlCenter
    End With

    ' Cartões de KPI (endereços fixos: Offset em célula mesclada pula a área inteira)
    addr = Array("E4", "I4", "M4", "Q4")
    lbl = Array("FATURAMENTO", "LUCRO", "Nº DE VENDAS", "TICKET MÉDIO")
    frm = Array("=GETPIVOTDATA(""Total Faturamento"",Tabelas!$R$3)", "=GETPIVOTDATA(""Total Lucro"",Tabelas!$R$3)", _
                "=GETPIVOTDATA(""Qtd Vendas"",Tabelas!$R$3)", "=IFERROR(E5/M5,0)")
    fmt = Array("$ #,##0", "$ #,##0", "0", "$ #,##0.00")
    For i = 0 To 3
        Set c = wsD.Range(addr(i))
        c.Resize(4, 4).Interior.Color = vbWhite
        c.Resize(4, 4).BorderAround xlContinuous, xlThin, , RGB(210, 214, 220)
        With c.Resize(1, 4)
            .Merge: .Value = lbl(i): .HorizontalAlignment = xlCenter
            .Font.Size = 9: .Font.Bold = True: .Font.Color = RGB(100, 110, 120)
        End With
        With c.Offset(1, 0).Resize(3, 4)
            .Merge: .Formula = frm(i): .NumberFormat = fmt(i)
            .Font.Size = 20: .Font.Bold = True: .Font.Color = RGB(33, 115, 70)
            .HorizontalAlignment = xlCenter: .VerticalAlignment = xlCenter
        End With
    Next i

    ' Gráficos
    Set co = wsD.ChartObjects(1): Set r = wsD.Range("E9:L25")
    co.Left = r.Left: co.Top = r.Top: co.Width = r.Width - 6: co.Height = r.Height
    With co.Chart
        .HasTitle = True: .ChartTitle.Text = "Faturamento x Lucro por Mês"
        .ShowAllFieldButtons = False: .Legend.Position = xlLegendPositionBottom
        .SeriesCollection(1).Format.Fill.ForeColor.RGB = RGB(33, 115, 70)
        .SeriesCollection(2).Format.Fill.ForeColor.RGB = RGB(242, 169, 0)
        .Axes(xlValue).TickLabels.NumberFormat = "$ #.##0"
    End With
    NovoGrafico wsD, wsD.Range("M9:T25"), ptR, xlBarClustered, "Faturamento por Região", RGB(33, 115, 70)
    NovoGrafico wsD, wsD.Range("E27:L43"), ptC, xlDoughnut, "Faturamento por Categoria", 0
    NovoGrafico wsD, wsD.Range("M27:T43"), ptV, xlBarClustered, "Ranking de Vendedores", RGB(242, 169, 0)

    ' Segmentações na coluna lateral
    For Each s In wsD.Shapes
        If s.Type = msoSlicer Then
            Select Case s.Name
                Case "Região": Set r = wsD.Range("B4:C15")
                Case "Categoria": Set r = wsD.Range("B17:C28")
                Case Else: Set r = wsD.Range("B30:C43")
            End Select
            s.Left = r.Left: s.Top = r.Top: s.Width = r.Width: s.Height = r.Height
        End If
    Next s
    ActiveWindow.Zoom = 60: ActiveWindow.DisplayHeadings = False
End Sub

Private Sub NovoGrafico(ws As Worksheet, r As Range, pt As PivotTable, tipo As Long, titulo As String, cor As Long)
    Dim co As ChartObject
    Set co = ws.ChartObjects.Add(r.Left + 6, r.Top, r.Width - 6, r.Height)
    co.Chart.SetSourceData pt.TableRange1
    co.Chart.ChartType = tipo
    With co.Chart
        .HasTitle = True: .ChartTitle.Text = titulo: .ShowAllFieldButtons = False
        .SeriesCollection(1).HasDataLabels = True
        If tipo = xlDoughnut Then
            .Legend.Position = xlLegendPositionRight
            .SeriesCollection(1).DataLabels.ShowValue = False
            .SeriesCollection(1).DataLabels.ShowPercentage = True
        Else
            .HasLegend = False: .HasAxis(xlValue) = False
            .SeriesCollection(1).Format.Fill.ForeColor.RGB = cor
            .SeriesCollection(1).DataLabels.NumberFormat = "$ #.##0"
            .ChartGroups(1).GapWidth = 60
            If pt.Name = "ptRegiao" Then .Axes(xlCategory).ReversePlotOrder = True
        End If
    End With
End Sub
Atenção

Os formatos numéricos usam $, que o Excel em português converte para R$. Escrever "R$ #,##0" no VBA gera RR$ na planilha.
